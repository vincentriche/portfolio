Internship at OOGarden

This work placement took place within the company OOGarden, French leader in the online sale of products for outdoor home improvement. At this time, the website did not display correctly on mobile devices, there was too many information and it was illegible.

The project consisted of making a Responsive Web Design prototype: a technique used to structure a web page with the aim of being adapted for mobile and tablets.
